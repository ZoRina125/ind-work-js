# Laboratory Work #6

##  Обзор проекта
Данный проект представляет собой высокоуровневое REST API для управления системой задач (To-Do List). Реализация выполнена на фреймворке **FastAPI** с соблюдением принципов многослойной архитектуры и строгой типизации данных.

---

* **Язык:** Python 3.10+
* **Фреймворк:** FastAPI (Asynchronous Server Gateway Interface)
* **Валидация данных:** Pydantic v2
* **Сервер:** Uvicorn
* **Документация:** Swagger UI (OpenAPI)

---
