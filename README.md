###  1. Описание проекта, цель и основные функции

**XP Food** — это интерактивное модульное веб-приложение (Single Page Application), представляющее собой цифровую книгу кулинарных рецептов из популярных игровых вселенных (*The Elder Scrolls V: Skyrim, World of Warcraft, The Witcher, Portal, Cyberpunk 2077* и др.). Уникальность проекта заключается в том, что все представленные игровые блюда адаптированы под **реальное приготовление в домашних условиях** с указанием точных пропорций и доступных ингредиентов. Интерфейс приложения выполнен в современной **лавандовой палитре** (Lavender Aesthetic), сочетающей мягкие пастельные фиолетовые фоны с глубокими контрастными элементами управления.

**Цель проекта:** Развитие и демонстрация практических навыков программирования на чистом JavaScript (Vanilla JS, ES6+), включая динамическое управление объектной моделью документа (DOM), обработку асинхронных концепций и пользовательских событий, реализацию клиентской валидации данных, фильтрацию массивов объектов, а также обеспечение персистентности данных (сохранение состояния) с помощью механизмов веб-хранилища без использования сторонних фреймворков и библиотек.

**Основные функциональные возможности:**
1. **Динамическая генерация интерфейса (DOM):** Карточки рецептов рендерятся динамически на основе структурированного массива объектов JS.
2. **Двухуровневая поисково-фильтрационная система:** Реализован реактивный («живой») поиск по ключевым словам, охватывающий одновременно названия блюд и игровые вселенные, совмещенный с фильтрацией по категориям (десерты, зелья/напитки, основное сытное меню).
3. **Модульная интерактивная система (Modal Windows):** Подробная информация о рецепте, включающая реальный пошаговый состав ингредиентов с граммовками, открывается во всплывающем модальном окне с эффектом размытия заднего плана.
4. **Валидация пользовательского ввода:** Интегрирована кастомная клиентская валидация формы добавления новых игровых рецептов. Система предотвращает некорректный ввод (пустые поля, отрицательные показатели восстановления здоровья HP) и динамически выводит понятные сообщения об ошибках.
5. **Сохранение прогресса (Data Persistence):** Использование `LocalStorage` гарантирует, что все созданные пользователем рецепты и изменения сохраняются локально в браузере и остаются доступными после перезагрузки страницы или закрытия вкладки.
6. **Адаптивный Layout:** Интерфейс построен с применением методологий CSS Grid и Flexbox, обеспечивая корректное отображение на смартфонах, планшетах и мониторах с высоким разрешением.

###  2. Стек технологий и архитектура

При разработке приложения использовался современный технологический стек веб-разработки без внешних зависимостей:
* **HTML5:** Семантическая разметка (`<header>`, `<main>`, `<section>`), обеспечивающая доступность и правильное SEO-структурирование.
* **CSS3:** Кастомные свойства (CSS Variables) для управления лавандовой палитрой, Grid Layout для отзывчивой сетки карточек, Flexbox для выравнивания элементов управления, CSS Transitions для плавных анимаций наведения (`hover`) и открытия модальных окон.
* **Vanilla JS (ES6+):** Модульная архитектура (`import`/`export`), стрелочные функции, деструктуризация объектов, методы перебора массивов (`filter`, `forEach`, `map`, `find`), обработка событий (`addEventListener`) и событийное делегирование.

**Архитектурная структура модулей (папка `js/`):**
* `recipes.js`: Модуль данных. Хранит массив из 11 базовых игровых рецептов с реальными ингредиентами. Экспортирует константу `initialRecipes`.
* `storage.js`: Сервисный модуль инкапсуляции работы с `Web Storage API`. Предоставляет методы `getRecipes()` и `saveRecipes()`.
* `app.js`: Центральный контроллер приложения. Координирует инициализацию, рендеринг DOM, фильтрацию данных, валидацию форм и логику модальных окон.

### 3. Инструкции по установке и запуску проекта

Так как приложение построено с использованием нативных JavaScript-модулей (`type="module"`), браузеры блокируют их загрузку при открытии файла напрямую через протокол `file:///` из-за политики безопасности CORS. Проект необходимо запускать строго через локальный веб-сервер.

#### Шаг 1: Клонирование репозитория
Склонируйте проект с удаленного репозитория Git на локальный компьютер:
```bash
git clone [https://github.com/ваш-аккаунт/xp-food.git](https://github.com/ваш-аккаунт/xp-food.git)
cd xp-food
```
#### Шаг 2: Запуск локального сервера
Вы можете использовать любой удобный инструмент для поднятия локального HTTP-сервера:
* **Вариант А (VS Code Live Server):** Откройте папку проекта в редакторе Visual Studio Code, нажмите правой кнопкой мыши на файл `index.html` и выберите пункт **«Open with Live Server»**.
* **Вариант Б (Node.js / npx):** Выполните в терминале команду:
  ```bash
  npx serve
  ```
#### Шаг 3: Просмотр приложения
Откройте браузер и перейдите по адресу, предоставленному сервером (обычно `http://127.0.0.1:5500`).

###  4. Ключевые фрагменты кода и технические решения

#### А. Реактивная фильтрация и сквозной поиск
Функция осуществляет регистронезависимый поиск одновременно по двум свойствам объекта (`title` и `game`), объединяя результат с логическим селектором категорий:

```javascript
function filterRecipes() {
    const query = searchInput.value.toLowerCase();
    const category = categorySelect.value;

    const filtered = recipes.filter(recipe => {
        const matchesSearch = recipe.title.toLowerCase().includes(query) || 
                              recipe.game.toLowerCase().includes(query);
        const matchesCategory = category === 'all' || recipe.category === category;
        return matchesSearch && matchesCategory;
    });

    renderRecipes(filtered);
}
```

### Б. Делегирование событий для динамических элементов
Вместо навешивания слушателей на каждую кнопку удаления или просмотра (что привело бы к утечкам памяти и багам при перерендере), слушатель назначен на общий контейнер recipes-container:

```javaScript
container.addEventListener('click', (e) => {
    const id = Number(e.target.dataset.id);
    if (e.target.classList.contains('delete-btn')) {
        recipes = recipes.filter(r => r.id !== id);
        Storage.saveRecipes(recipes);
        filterRecipes();
    } else if (e.target.classList.contains('view-btn')) {
        const recipe = recipes.find(r => r.id === id);
        openModal(recipe);
    }
});
```
